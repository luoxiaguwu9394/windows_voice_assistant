壹 · 应用白名单
壹 · 续

内置九个应用——记事本、计算器、资源管理器、命令提示符、 命令行窗口、代码编辑器、谷歌浏览器、微软浏览器、系统设置—— 始终可用,无需登记;它们按 App Paths 与 PATH 自适应,装在哪都能找到。

自定义应用来自开始菜单与 App Paths 的扫描,或手动登记。 「启动命令」填绝对路径(装在自定义目录的微信就是这样),或系统能找到的程序名; 若启动命令与进程映像不同(如微信的 Weixin.exe),请补映像名,关闭与验证靠它。

访客禁开

出现在下列名单中的应用,访客一律打不开——默认含命令提示符与命令行窗口。

贰 · 唤醒词

每行一个,共 1–8 个,每个 2–12 个字;中英文都可以。

↻ 重启助手后生效

贰 · 续

唤醒词由本地 KWS 模型监听,改词不需要联网,也不动模型本身—— 词表指纹变化时会自动重建发音缓存,重启助手时加载。

挑词的经验:三四个字、声调起伏大、日常口语里少见的组合最稳; 太短的词容易被日常对话误唤醒,太长的词喊起来累。

叁 · 语音

↻ 三项都需要重启助手后生效

叁 · 续

语速是强杠杆:时长与速度成反比。1.0 ≈ 播报腔, 0.9 ≈ 自然对话(当前默认),0.8 往下明显变慢。

音调以模型原声为 1.0:调低偏童声,调高偏中性沉稳。 两个旋钮互不影响——语速管快慢,音调管高低。

访客语速是绝对值,不是相对主人的倍率; 单说话人模型下访客只靠它区分音色,别调成和主人一样。

肆 · 常规
✓ 即时生效

城市只在「今天天气怎么样」这类不带地名的话里使用; 你明确说了城市时,以句子里的为准。

改动保存后即时生效——下一次天气问答就用新城市, 连助手都不用动。
