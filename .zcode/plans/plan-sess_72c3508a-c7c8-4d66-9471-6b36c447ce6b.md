# WinVoice 一键安装向导（分发方案）

## 目标

一个 `WinVoice-Setup.exe`（约 250–300MB），用户点击后由 tkinter 向导完成全部部署：释放内嵌运行时、下载模型（支持代理/镜像/断点续传）、选择并测试音频设备、生成 config.yaml、可选云端 key、可选 DSH agent、说话人注册、`--check` 自检、建快捷方式/自启。装完从桌面快捷方式直接启动，不再需要 Python/pip/编译/手动配置。

## 核心架构决策（将写入 docs/adr/0001）

**应用本体不做 PyInstaller 冻结，而是「内嵌 Python 运行时 + 原始源码树」随安装器分发。** 理由：
- 全应用按 CWD 解析路径（config/models/tools/logs/runtime），安装目录**复刻仓库布局**、启动时 CWD=安装目录（与 `run.ps1` 同思路），`winvoice/` 源码、`.pylibs`、DSH 的 `PROJECT_ROOT` 全在真实文件树上——**winvoice 包零改动**。
- PyInstaller 冻结则会踩：`sys.executable -m winvoice.mcp_server` 被钉进 DSH bundle、`__file__` 派生路径、sherpa-onnx 数据文件等一堆坑。
- 模型 ~3GB 在线下载（用户已选）：安装器内置 runtime 载荷（embeddable Python 3.12 + 构建期装好的全部依赖 + llama.cpp b7376 CPU 版 + `.pylibs` + winvoice 源码 + config 模板，xz 压缩），用户侧**零 pip、零编译**。

安装目录默认 `%LOCALAPPDATA%\WinVoice`（用户可改），因为 `models/`（KWS 缓存、声纹档案）、`runtime/`、`logs/` 必须可写，不能装进 Program Files。

用户机安装后布局 = 仓库布局 + `python\`（内嵌解释器）+ `WinVoice.exe`（setup exe 复本，重进向导用）。快捷方式直接指向 `python\python.exe -m winvoice`（lnk 设参数与工作目录、设图标），**不单独造 launcher exe**。

## 向导流程（tkinter，中文，线性分页 + 底部上一步/下一步，长任务走 worker 线程 + 日志框 + 进度条）

1. **欢迎/系统检查**：Windows 版本、内存（自动推荐 LLM 档位：≥16G→3B、≥8G→1.5B、≥4G→0.5B）、磁盘空间；检测已装实例 → 变为「已装 vN：重新配置 / 修复运行时（保留 models 与 config）/ 启动」重入模式。
2. **安装位置**：默认 `%LOCALAPPDATA%\WinVoice`，校验可写、剩余空间。
3. **网络**：直连 / HTTP 代理（下载与 GitHub 用）/ HF 镜像端点（`hf-mirror.com`），传给后续所有下载子进程。
4. **释放运行时**：解压内置载荷到安装目录（xz 解压，秒级～分钟级）。
5. **模型下载**：档位选择（默认按内存推荐）+ 复用 `scripts/download_models.py` 子进程（core 集不含 458MB 流式 ASR 备用模型，高级页可勾选）；跑完自动 `--seal` 写 `models/integrity.json`（启动校验从第一天就生效）。
6. **音频设备**：新增 `scripts/audio_probe.py`（内嵌解释器子进程，复用 `winvoice.audio.playback` 的真实路由逻辑）：`list` 出 JSON 设备表、`play-test` 播测试音、`record-level` 录音出电平。向导展示下拉框 + 实测按钮，结果写入配置。
7. **生成 config.yaml**：从新文件 `config/config.template.yaml`（带 `@TOKEN@` 占位、保留注释）做纯文本替换渲染：server_binary（按实际解压目录）、model_file（所选档位）、音频四项、`weather.city` 输入框。已存在则先备份 `config.yaml.bak-<日期>`。
8. **云端 LLM 配置页**（可选）：REMOTE_API_KEY（→ `setx` + `llm.remote.enabled=true` + base_url 可改）、DEEPSEEK_API_KEY（DSH 云端升级用，→ `setx`）。
9. **DSH Agent 层**（可选，默认勾选）：`.pylibs` 已预置在载荷里，跑 `install_dsh_bridge.py --install` + 置 `dsh.enabled/dsh.local.enabled=true`。
10. **说话人注册**（可选，可跳过）：弹独立控制台跑 `python -m winvoice.enroll --speaker me`，向导轮询 `models/sv/profiles/me.json` 出现后继续。
11. **自检**：子进程跑 `python -m winvoice --check`（cwd=安装目录），输出实时进日志框，退出码 0 才放行（失败可返回上一步）。
12. **快捷方式/完成**：桌面 + 开始菜单 `WinVoice 语音助手.lnk`（目标=内嵌 python、参数=`-m winvoice`、工作目录=安装目录、设图标）；勾选「开机自启」→ `shell:startup` 同款 lnk；完成页「立即启动」。

## 风险与缓解

- **onefile 杀软误报**（PyInstaller 常见）：优先实测 Defender；误报严重则切换 onedir+zip 分发（架构不变）。
- **onefile 每次启动解压 ~300MB 载荷（约 5–15s）**：用 PyInstaller `--splash` 加启动画面；用户通常只点一次。
- **中文/空格安装路径**：Popen 列表传参天然支持 unicode；向导对异常路径给出警告，默认路径规避。
- **首次 `--check` 较慢**（全量哈希 + llama-server 冷启动 ≤60s）：日志框实时滚动，UI 明示阶段。
